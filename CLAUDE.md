# chinese-sim · ИИ-собеседник для разговорного китайского

Учебное веб-приложение: живой разговор с ИИ, который играет роль китайца в бытовой ситуации
(аэропорт, такси, отель, ресторан, магазин, дорога, знакомство). Уровень ученика — HSK 2-3.
Ученик (Дима, из России, едет в Чэнду) отвечает пиньинем; ИИ проверяет, поправляет и ведёт диалог.

## Как это работает
- Пользователь выбирает ситуацию → ИИ (роль из `scenarios.js`) начинает разговор по-китайски.
- **Слушай-сначала:** реплика собеседника сперва только озвучивается (🔊), текст скрыт.
  После ответа пользователя открывается пиньинь + иероглифы; кнопка «перевод + разбор» — русский и разбор слов.
- Пользователь пишет ответ **пиньинем латиницей**; незнакомые слова можно вставлять в скобках
  на англ./рус.: `ni keyi bangzhu wo (get a taxi)?` — ИИ понимает и подставляет нужное.
- ИИ возвращает: оценку ответа (verdict good/ok/wrong) + объяснение ошибок по-русски +
  исправленную версию фразы пользователя (`fixed`) + как сказал бы носитель (`native`) +
  следующую реплику собеседника (`reply`) с уточняющим вопросом. **Помнит весь контекст разговора.**
- «🤔 Не понял вопрос» — раскрывает текст+перевод+разбор текущей реплики.
- «🙈 Не знаю, что сказать» — просит у ИИ подсказку по-русски (сцену не двигает).
- Озвучка — встроенный голос iPhone (Web Speech API); в настройках выбор голоса и скорости.

## ИИ-мотор
- **Google Gemini** (`gemini-2.0-flash`), бесплатный tier, вызывается **прямо из браузера** (CORS разрешён).
- Ключ пользователя хранится ТОЛЬКО в `localStorage` (`cs_gemini_key`) — **в репозиторий не попадает, никогда не коммитить.**
- Формат ответа фиксирован через `responseSchema` (Gemini structured output) → надёжный JSON.
- Логика клиента и системный промпт — в `gemini.js`. Меняешь поведение ИИ — правишь `SYSTEM` там же.
- Требуется интернет во время разговора. Оболочка приложения кэшируется (`sw.js`), но запросы к Gemini — нет.

## Файлы
- `index.html` — разметка, стили, вся клиентская логика (экраны: ввод ключа / меню / настройки / чат).
- `gemini.js` — клиент Gemini: системный промпт, схема ответа, `start()`/`turn()`/`hint()`.
- `scenarios.js` — ситуации (роли для ИИ): `{id,icon,title,desc,scene}`. **Новые ситуации добавлять сюда.**
- `sw.js`, `manifest.json`, `icon.svg` — PWA / «на экран Домой».

## Как запустить локально
```
cd ~/Projects/chinese-sim && python3 -m http.server 8000
```
Проверка синтаксиса без браузера: `node --check gemini.js && node --check scenarios.js`.
