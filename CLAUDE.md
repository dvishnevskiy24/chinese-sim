# chinese-sim · Симулятор разговорного китайского

Учебное веб-приложение для запоминания разговорного китайского через живые бытовые диалоги
(аэропорт, такси, отель, ресторан, магазин, спросить дорогу). Уровень HSK 2-3.

## Что делает
- Собеседник (NPC) выдаёт реплику: пиньинь + перевод + озвучка (иероглифы скрыты под кнопкой).
- Пользователь отвечает **пиньинем латиницей** (тоны/знаки/опечатки не важны — проверка ленивая).
- Кнопка «🤔 Не понял вопрос» → перевод реплики + разбор слов + что ответить.
- Кнопка «🙈 Не знаю, что сказать» → образцовый ответ носителя + разбор + подсказка.
- Озвучка — встроенный голос iPhone через Web Speech API (бесплатно, работает офлайн после загрузки голоса).
- Настройки (автоозвучка / показ иероглифов / скорость речи) сохраняются в localStorage.

## Как запустить
Это статический сайт, сборки нет. Локально:
```
cd ~/Projects/chinese-sim && python3 -m http.server 8000
```
и открыть http://localhost:8000 . На телефоне — через GitHub Pages (см. ниже).

## Файлы
- `index.html` — вся разметка, стили и логика приложения.
- `scenarios.js` — контент диалогов. **Добавлять сценарии/реплики только здесь.**
- `sw.js` + `manifest.json` + `icon.svg` — PWA/офлайн, «добавить на экран Домой».

## Формат сценария (scenarios.js)
```js
{ id, icon, title, desc, turns:[ {
    npc:{hanzi,pinyin,ru},         // реплика собеседника
    accept:["...","..."],          // принимаемые ответы (пиньинь без тонов, нижний регистр)
    model:{hanzi,pinyin,ru},       // образцовый ответ
    words:[["pinyin","перевод"]],  // разбор слов
    tip:"подсказка что сказать"
} ] }
```
Проверка ответа: нормализация (снятие тонов, v→ü→u, удаление пробелов/знаков) + подстрока + Левенштейн ~22%.

## Конвенции
- Контент — на пиньине без обязательных тонов в `accept` (пользователь пишет латиницей).
- Никаких платных API и внешних зависимостей: только встроенный TTS браузера.
- Прогресс/контекст — в GitHub Issues репозитория.
